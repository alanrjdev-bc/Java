# Java Learning Repository

Welcome to my Java learning repository! 👋

This repository contains the Java programs and practice exercises I
write while learning Java step by step. My goal is to improve my
programming fundamentals, problem-solving skills, and object-oriented
programming knowledge through regular practice.

## Topics Practiced

-   Java basics, variables, data types, and operators
-   Conditional statements and loops
-   Arrays (1d array)
-   Strings and string manipulation
-   Methods, parameters, and return values
-   Classes and objects
-   Constructors and constructor overloading
-   `this` keyword and constructor chaining
-   Static and non-static members
-   Encapsulation
-   Inheritance and its types
-   Method overloading and method overriding
-   Compile-time and runtime polymorphism
-   Upcasting and downcasting
-   Abstract classes and abstract methods
-   Interfaces
-   `instanceof` operator
-   Java's `Object` class methods, including `toString()`, `equals()`,
    and `hashCode()`
